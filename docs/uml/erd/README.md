# TableCheck Entity Relationship Diagram

**Last updated:** Week 13  
**Source:** `database/schema.sql`

## Description

This ERD represents the current PostgreSQL database schema for the TableCheck application.

The `restaurant_tables` table stores restaurant table names, capacities, occupancy status, and update timestamps.

The `staff_users` table provides a foundation for future staff authentication and role-based access.

## Relationships

The current schema does not define any foreign-key relationship between these two tables. Therefore, they appear as separate entities in the ERD.
